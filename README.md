# SkillSwap

SkillSwap is a peer-to-peer learning marketplace. Every member can both teach and learn; admins use a separate operational account.

## Current build

This repository currently contains a responsive, clickable product prototype built from the master PRD. It includes:

- A member overview with teaching skills, learning goals, matches, and upcoming exchanges
- Discover search and category filters
- Add/remove skills for both sides of one member profile
- Save teachers and send a sample learning request
- Exchange, credit activity, and separate admin preview screens

The prototype uses sample data and browser local storage. Authentication, database persistence, real scheduling, payment/credit settlement, messaging, and secure admin authorization are not implemented yet. The admin screen is only a visual preview and is not an access-control boundary.

## Run locally

Open `index.html` in a browser. No package installation or build step is required for this prototype.
